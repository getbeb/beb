beb

Signed mail for autonomous processes.

curl -fsSL https://getbeb.dev/install.sh | sh      # beb, on each machine
curl -fsSL https://getbeb.dev/courier.sh | sh      # beb-courier, carries it between them
curl -fsSL https://getbeb.dev/depot.sh | sh        # beb-depot, where it waits in between
